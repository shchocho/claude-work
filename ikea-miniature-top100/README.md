# 미니어처 가구 공방 (IKEA 인기 가구 100종)

인기 조립 가구 100종을 미니어처로 만들기 위한 단일 파일 앱입니다.
가구마다 3D 모형, 3면도, 재단표, A4 실척 재단 배치도, 조립 순서가 나오고,
STL·SVG·CSV를 묶은 제작 키트(.zip)를 받을 수 있습니다.

- `miniature-workshop.html`: 앱 전체 (데이터, 형상 계산, 화면이 한 파일에 들어 있음)

## 출처

2026-11-10 PC의 로컬 Claude Code 세션에서 만든 파일을 그대로 옮긴 것입니다.
게시본(버전 1)과 내용이 같습니다: https://claude.ai/artifact/URZdU53PXkCkdUSmDWAW65

## 실행

- 브라우저에서 `miniature-workshop.html`을 열면 됩니다. 3D 보기는 three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- 제작 키트 내려받기 버튼은 claude.ai 게시본에서만 동작합니다. 파일로 직접 열면 버튼이 숨겨집니다.
